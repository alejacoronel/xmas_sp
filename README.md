# Super Piña Bros. — Christmas Edition 🍍🎄

A short, original, mobile-friendly retro pixel platform game.

- Desktop: arrow keys or A/D to move; Space, W, or Up Arrow to jump.
- Phone: use the on-screen arrows and A/JUMP button.
- Jump across the blocks, avoid snow buddies, collect piñas, and reach the flagpole to rescue the princess.

## Publish with GitHub Pages
1. Unzip this folder.
2. Upload `index.html`, `style.css`, and `game.js` to your GitHub repository root.
3. Commit the changes.
4. In Settings → Pages, select deployment from the `main` branch and `/ (root)`.
5. Open your GitHub Pages URL on your phone.

All game sprites are original canvas-drawn pixel art; no Nintendo sprites or music are used.
